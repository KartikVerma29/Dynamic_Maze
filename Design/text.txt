basic idea
   Dynamic maze
      there are many classical static maze, where we need to find path. Path or solution is fixed, won't change.
      Unlike this, our maze game is trying to bring uniqueness. 
      Making simple maze game to be dynamic, changing layout/wall, where multiple path/solutions exiting but won't be fixed, keep changing as defined set of rules

   considering few conceptual idea,
   1. maze changes after every few steps
   2. maze might change after reaching certain to goal
   3. maze will and must maintain a real & possible solution
   4. maze won't cage player while changing layout

      there could be differet type maze to play or modes
      1. dynamic maze
      2. dark maze (where only surrounding maze is visible, maybe dynamic or not)
      3. gaunlet/castle (similar to pacman, but twist of dynamic)
